# Visitor log (disabled)

The portfolio no longer calls IPWhois or sends visitor information to the Google Apps Script web app. The production endpoint configuration and browser analytics code were removed.

`Code.gs` is retained only as a record of the former Google Apps Script implementation. A previously deployed Apps Script web app may still exist in the owning Google account, but the portfolio does not call it. The private Sheet may still contain past visits; disabling collection does not delete those rows.
